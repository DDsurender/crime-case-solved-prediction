 What each package is for

text
pandas        → Data loading and data processing
numpy         → Numerical operations and transformations
scikit-learn → Preprocessing, train/test split, evaluation, GridSearchCV
xgboost      → Final Machine Learning model
joblib        → Saving/loading model and preprocessor
fastapi      → Backend REST API
uvicorn      → Runs the FastAPI server
pydantic      → API request validation

Install everything

From the Crime folder:

pip install -r requirements.txt

Then your backend can be started normally:

powershell

cd api
uvicorn Crime_api:app --reload
